# JDBC

## Definition
- **JDBC** is the standard Java API to connect applications with relational databases, execute SQL, and process results.  
- Flow: **Java App → JDBC API → JDBC Driver → Database**


## Architecture
- **DriverManager** → Manages drivers, creates connections.  
- **Connection** → Represents DB session.  
- **Statement / PreparedStatement / CallableStatement** → Execute SQL.  
- **ResultSet** → Holds query results.  
- **SQLException** → Handles DB errors.


## Workflow
1. Load/Register Driver (optional in modern JDBC).  
2. Establish Connection.  
3. Create Statement/PreparedStatement.  
4. Execute SQL (`executeQuery`, `executeUpdate`).  
5. Process ResultSet.  
6. Close resources (prefer try‑with‑resources).


## Key APIs
- **Statement** → Executes static SQL.  
- **PreparedStatement** → Parameterized SQL, prevents SQL injection, better performance.  
- **CallableStatement** → Calls stored procedures.  
- **ResultSet** → Cursor for query results (`next()`, `getInt()`, `getString()`).  
- **SQLException** → Provides error details (`getMessage()`, `getSQLState()`, `getErrorCode()`).


## Important Methods
- `executeQuery()` → For `SELECT`, returns ResultSet.  
- `executeUpdate()` → For `INSERT/UPDATE/DELETE`, returns affected rows.  
- `execute()` → For unknown SQL type (returns boolean).  


## Transactions
- Default: auto‑commit = true.  
- Disable auto‑commit for manual control:  
  - `commit()` → Save changes.  
  - `rollback()` → Undo changes.  
- Ensures **atomicity** (e.g., money transfer).


## Batch Processing
- Use `addBatch()` + `executeBatch()` for bulk inserts/updates → reduces round trips.


## Resource Management
- Always close **Connection, Statement, ResultSet**.  
- Use **try‑with‑resources** for automatic cleanup.


## JDBC vs JdbcTemplate vs JPA
| **JDBC** | **JdbcTemplate** | **JPA** |
|----------|------------------|---------|
| Low-level, verbose | Simplified JDBC | ORM abstraction |
| Manual resource handling | Auto resource mgmt | Entity lifecycle |
| SQL only | SQL only | JPQL/derived queries |
| Max control | High control | High abstraction |


## Notes
- **Preferred API** → `PreparedStatement` (security + performance).  
- **Transactions** → `commit()` / `rollback()`.  
- **ResultSet** → Cursor starts before first row; use `next()`.  
- **Auto‑commit** → True by default.  
- **Cheat memory line** → *Connect → Prepare → Execute → Process → Commit/Rollback → Close*
